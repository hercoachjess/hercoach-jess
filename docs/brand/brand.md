## Colour palette
| Token        | Hex       | Use                                  |
|--------------|-----------|--------------------------------------|
| Bone         | `#F6F1EA` | Page background                      |
| Ink          | `#211C1A` | Primary text, dark sections          |
| Rosewood     | `#B67F70` | Accent (buttons, italic highlights)  |
| Blush soft   | `#E7D3CB` | Accent on dark backgrounds           |
| Line         | `#D8CCC0` | Hairline borders/dividers            |
| Muted        | `#8A7E74` | Secondary/label text                 |
| Amber dot    | `#C08A4A` | The dot in the logo — small accents  |

## Typography
- **Headings:** Cormorant Garamond (use italic for accent words). Google Fonts.
- **Brand/body:** Jost. Google Fonts.
- **Labels/eyebrows:** Montserrat, uppercase, letter-spacing ~0.18em. Google Fonts.

## Logo files (in /public)
- `logo-cream.png` — cream wordmark, transparent → use on dark/ink backgrounds
- `logo-ink.png` — ink wordmark, transparent → use on light/bone backgrounds
- `logo-hero.png` — ink wordmark on cream → fallback/social
- `portrait.jpg` — headshot for the About section
- `lifestyle.jpg` — infinity-pool shot for a full-bleed section

## Voice
Warm, credible, editorial. Tagline: **"less restriction, more you."**
Lead with the registered-dietitian credibility — it's the differentiator.
